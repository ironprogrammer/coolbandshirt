# cool band shirt

Microsite for **coolbandshirt.com** — a wip landing page for the shirt.

- Static single page, hosted on **GitHub Pages**.
- Type is [Fraunces](https://fonts.google.com/specimen/Fraunces) (black weight, max SOFT) — an open-source stand-in for Cooper Black.
- Local preview via Laravel Valet at http://coolbandshirt.test
